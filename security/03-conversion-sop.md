# SOP 03: 21-Day Trial Conversion Procedure

**Owner:** Growth Lead  
**Author:** Manus AI  
**Status:** Ready for adaptation  
**Objective:** Convert qualified free-trial members into annual members through clear value proof, transparent timing, and confident offer presentation.

## Purpose

This SOP defines the communication and conversion process for a 21-day free membership trial followed by a $200 annual plan. The goal is not to pressure every user into payment. The goal is to help the right users recognize the value they have already experienced and understand why full-year access is the logical next step.

Conversion should be treated as a continuation of the experience, not a surprise payment moment.

## Conversion Philosophy

> **Conversion principle:** A member should choose the annual plan because the trial has already made the value visible.

| Conversion Driver | Description | Required Proof |
|---|---|---|
| Speed | The member got started quickly | Setup completed in the first session |
| Usefulness | The member experienced a real benefit | First win completed |
| Confidence | The member understands what is included | Benefits and terms are clear |
| Value | The annual plan feels reasonable | $200/year is connected to year-round access |
| Trust | The member does not feel trapped | Billing and cancellation information is transparent |

## Communication Timeline

The trial should include a small number of high-quality messages. Too many reminders can feel desperate; too few can cause the user to forget the trial entirely.

| Trial Day | Message Purpose | Core Message |
|---|---|---|
| Day 0 | Welcome and activation | "Your 21-day access is live. Start with quick setup." |
| Day 3 | First-win reinforcement | "Here is the fastest way to get more value." |
| Day 7 | Usage and value reminder | "You have had a week to explore. Here is what members usually do next." |
| Day 14 | Annual plan introduction | "Keep full-year access for $200 after your trial." |
| Day 20 | Final trial reminder | "Your trial ends tomorrow. Continue year-round if it is working for you." |
| Day 21 | Conversion decision | "Choose annual access or let the trial end." |

## Procedure

### 1. Confirm Trial Activation

The user should receive immediate confirmation that the free period has started. The message should include the start date, end date, and the next action. If billing applies after the trial, that timing should be easy to understand.

**Trial activation copy:**

> **"Your 21-day access is active. Start with the quick setup today, explore the full experience, and decide before your trial ends whether year-round access for $200 is right for you."**

### 2. Reinforce Value Before Selling

The first conversion-related message should not be a sales pitch. It should help the member get more value from the trial. A user who receives value is easier to convert than a user who receives reminders only.

| Message Type | Good Version | Weak Version |
|---|---|---|
| Value reminder | "Try this recommended setup path to unlock your next benefit." | "Do not forget to upgrade." |
| Annual offer | "Keep year-round access for $200 when your trial ends." | "Pay now before you lose access." |
| Final reminder | "Your trial ends tomorrow; here are your options." | "Last chance, hurry." |

### 3. Present the Annual Offer Clearly

The annual membership should be presented as the natural continuation of the trial. The message should avoid sounding like a hidden fee or sudden upsell.

**Annual offer copy:**

> **"If the trial is helping, keep the full membership active year-round for $200. You will continue access without interruption and keep the same guided experience, updates, and support path."**

### 4. Handle Objections Professionally

The most common objections will likely relate to price, usage, trust, and clarity. Each objection should be answered with calm, specific language.

| Objection | Recommended Response |
|---|---|
| "I am not sure I will use it enough." | "Use the rest of the trial to complete the recommended path. If it is not useful, you should not continue." |
| "Is $200 worth it?" | "The annual plan is designed for members who want year-round access rather than short-term experimentation." |
| "What exactly do I get?" | "The membership includes the access, guidance, updates, and support described on the membership page." |
| "Can I cancel?" | "Cancellation terms should be clearly explained before payment, and the user should never have to guess." |

### 5. Close With Choice, Not Pressure

A premium offer should feel confident enough to let the user decide. The final message should present two honest options: continue with annual access or let the trial end.

**Final-day copy:**

> **"Your 21-day trial ends tomorrow. If the membership is working for you, keep year-round access for $200. If it is not the right fit, you can let the trial end without continuing."**

## Quality Control

Conversion is healthy when paid members understand what they bought and feel good about the decision. If users convert but complain later that the terms were unclear, the conversion SOP has failed.

| Review Area | Passing Standard |
|---|---|
| Trial ending | User knows when the trial ends |
| Annual price | User sees the $200/year price before payment |
| Included value | User understands the core benefits |
| Support | User knows where to get help |
| Tone | Messages are confident, not manipulative |
